# SN Sergio Nxobei The Barber – website

Run: `npm start` (or `node server.js`). Node 18+; there are no dependencies, so `npm install` is not needed.
- Customer site: http://localhost:3000/
- Admin panel:   http://localhost:3000/admin/  (default password `sergio2026`, change it in Settings)

Options: `PORT=8080 ADMIN_PASSWORD=yourpassword node server.js`
Data lives in `data/db.json` (created on first run); uploaded photos go to `images/gallery/`. Back both up.
Needs a Node host (not static hosting).
